ASSISTANT MAINTENANCE — DOSSIER COMPLET POUR GITHUB PAGES

Fichiers : index.html, manifest.webmanifest, sw.js, icon-192.png, icon-512.png et .nojekyll.

INSTALLATION SUR GITHUB PAGES
1. Décompresser le ZIP.
2. Dans le dépôt GitHub (branche main), déposer LES FICHIERS contenus dans le dossier, à la racine du dépôt (pas le dossier englobant et pas le ZIP).
3. Dans Settings > Pages > Build and deployment : Source = Deploy from a branch ; Branch = main ; Dossier = /(root) ; Save.
4. Ouvrir l'adresse https://<utilisateur>.github.io/<depot>/ dans Chrome Android.
5. Menu Chrome ⋮ > Installer l'application (ou Ajouter à l'écran d'accueil).

MISE À JOUR : remplacer les fichiers en conservant exactement la même adresse du site.
SAUVEGARDE : les interventions et photos sont stockées localement sur le téléphone, dans le navigateur, et ne sont PAS dans le ZIP ni sur GitHub. Ne videz pas le stockage du navigateur ; ne désinstallez pas l'ancienne installation avant d'avoir vérifié les données. Une ouverture depuis file:// et depuis https:// n'utilise pas le même stockage : l'historique ne se transfère pas automatiquement.
PRIVACITÉ : les fichiers de l'application publiés sur GitHub Pages peuvent être publics. Ne publiez jamais de rapports, de photos d'interventions ou de données confidentielles dans le dépôt.
FONCTIONNALITÉS : interventions avec durée en minutes, compteur journalier, pièces sorties CA / désignation / quantité et modification, photos, historique et suppression, mail prérempli, rapport à copier.
NON INCLUS : lecture automatique des étiquettes par photo (fonctionnalité envisagée, non intégrée).
